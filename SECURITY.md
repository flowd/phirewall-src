# Security Policy

**Please do not report security vulnerabilities through public issues, pull requests, or discussions.**

Email security reports to **sascha.egerer@flowd.de**. The PGP key and the supported versions are
documented in the [security policy of the core package](packages/phirewall/SECURITY.md). The policy of the
OWASP CRS extension has additional scope notes: [packages/phirewall-preset-owasp-crs/SECURITY.md](packages/phirewall-preset-owasp-crs/SECURITY.md).
